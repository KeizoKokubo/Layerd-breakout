# Layerd Breakout

three.js で描く、半透明ガラスブロックのブロック崩しです。
GitHub Pages でそのまま遊べます。

- **トップ（バージョン選択）**: https://keizokokubo.github.io/Layerd-breakout/
- **ダブルレイヤー版**: 手前=暖色・奥=寒色の二層が重なった高難度版。パドルは共通、ボールはレイヤーごとに1個ずつ
- **シングル版**: 虹色グラデーション45ブロックの通常版

## 操作

- パドル移動：マウス / タッチ / キー（スマホは←→、PC・タブレットは↑↓）
- 発射・一時停止：クリック / スペース
- リスタート：R

## レイアウト

- レイアウトはウィンドウの形で自動で決まります：横長の窓では横レイアウト（ブロック右・パドル左）、縦長の窓では縦レイアウト
- 横レイアウトではフィールド自体を横長にしてパドルとブロックの距離を約2倍に取り、ボールが届くまでの時間＝操作の余裕を稼いでいます
- プレイ中にウィンドウサイズを変えると、形に合わせてレイアウトが切り替わります。ブロックの残りやスコアはそのまま引き継がれます

## 技術メモ

- 描画は three.js（CDN から読み込み。要ネット接続）
- ブロックは半透明マテリアル＋輪郭線でガラス感を出し、ダブル版では2レイヤーを半ブロックずらして配置し、`depthWrite: false` と奥→手前の描画順で重なりの色が混ざって見えるようにしています
- 物理は XY 平面上の 2D 判定で、描画だけを 3D にしています
